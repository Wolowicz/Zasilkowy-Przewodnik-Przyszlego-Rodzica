# Zgłaszanie problemów bezpieczeństwa

Repozytorium jest prywatne. Zgłoś problem właścicielce projektu prywatnym kanałem lub funkcją prywatnego zgłoszenia GitHub, jeśli jest dostępna. Nie publikuj tokenów, prawdziwych profili, danych medycznych ani pełnych logów zawierających pytania.

Podaj wersję/commit, funkcję, minimalne kroki z fikcyjnymi danymi, oczekiwany i rzeczywisty wynik oraz zakres zagrożenia. Dołącz wyłącznie zanonimizowane materiały. Nie testuj na cudzych profilach i kontach.

Przy ujawnieniu klucza najpierw unieważnij go u dostawcy i zastąp sekretem w backendzie. Następnie sprawdź zakres wykorzystania i usuń sekret z materiałów/historii zgodnie z ustaloną procedurą. Sama prywatność repozytorium nie chroni ujawnionego klucza.

Nie ustalono jeszcze formalnego SLA ani programu bug bounty. [Model danych i znane ryzyka](docs/PRYWATNOSC-I-BEZPIECZENSTWO.md).
